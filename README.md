# IDH Sistemas de Gestión

Plataforma web corporativa de **IDH Sistemas de Gestión**, organización especializada en consultoría, formación, auditoría, mejora continua y acompañamiento en sistemas de gestión.

El proyecto tiene como objetivo sustituir la antigua presencia web por una plataforma moderna, segura, accesible, escalable y preparada para incorporar nuevos servicios digitales.

---

## Sobre IDH Sistemas de Gestión

IDH acompaña a empresas, instituciones, organizaciones y profesionales en el diseño, implementación, mantenimiento y mejora de sus sistemas de gestión, procesos y estrategias.

Sus principales ámbitos de trabajo incluyen:

- Sistemas de gestión.
- Gestión del riesgo.
- Consultoría organizacional.
- Formación especializada.
- Auditoría y evaluación.
- Calidad.
- Seguridad y salud en el trabajo.
- Gestión ambiental.
- Seguridad de la información.
- Mejora continua.
- Sostenibilidad.

La identidad corporativa se resume en:

> Soluciones · Innovación · Gestión del Riesgo

---

## Objetivo del proyecto

Construir una plataforma corporativa que transmita desde el primer momento:

- Profesionalidad.
- Transparencia.
- Confianza.
- Seguridad.
- Fortaleza.
- Innovación.
- Cercanía.
- Rigor técnico.

La web no debe parecer una plantilla genérica. Debe ofrecer una experiencia visual limpia, moderna, intuitiva y coherente con una consultora especializada en gestión y prevención de riesgos.
